## Что сделано

### 1. App.jsx — полная замена (66 → 58 строк)

Старая версия:
- `ErrorBoundary` (class component) встроен прямо в App.
- Lazy-загрузка всех страниц через `React.lazy` + `Suspense`.
- `ProtectedRoute` — обёрточный компонент для авторизованных роутов.
- Роуты: `/`, `/login`, `/dashboard`, `/editor`, `/project/:id`, `/publish/:id`, `/billing`, `/admin`.

Новая версия:
- Убраны `ErrorBoundary`, `lazy`/`Suspense`, `ProtectedRoute` — весь бандл один чанк (309 KB gzip 95 KB, приемлемо).
- Добавлен `AdminRoute` — гейт `/admin` через `isAdmin(user)` из `lib/adminConfig.js`. Не-админа кидает на `/dashboard`, гостя — на `/login`.
- Добавлен `BrowserRouter` внутрь App (раньше был в `main.jsx` или Layout).
- Роуты `/project/:id` и `/publish/:id` убраны из маршрутизации (страницы остались в `src/pages/`, но не подключены).
- Импорты без расширений `.jsx` (Vite резолвит автоматически).

### 2. lib/adminConfig.js — НОВЫЙ файл (17 строк)

- `ADMIN_EMAILS` — массив почт, которым показывается раздел «Админ» даже если `role !== 'admin'` (подстраховка на случай, если бэкенд не проставил роль).
- `isAdmin(user)` — проверяет сначала `user.role === 'admin'` (основной путь через бэкенд + `ADMIN_EMAIL`), потом fallback на список почт.
- Сейчас в списке: `ddv1121@yandex.ru`.

### 3. Layout.jsx — полная замена (291 → 101 строка)

Старая версия:
- Сложная шапка с мобильным бургер-меню, `GenerationProgress` компонент, много состояний.
- Стили через объект `S` с вложенными вычисленными свойствами.

Новая версия:
- Минималистичная шапка кабинета: лого VideoAI, навигация (Проекты / Создать клип / Тарифы / Админ), баланс кредитов, аватар-кнопка выхода.
- Пункт «Админ» (иконка Shield) — условный, показывается только при `isAdmin(user) === true`.
- На гостевых страницах (`/`, `/login`) шапка кабинета скрыта — `<Outlet />` без хедера.
- Общий фон страниц: `linear-gradient(150deg, #EFF6F0 → #EBF3F5 → #F3EBF5)`.
- Glass-эффект шапки: `rgba(247,250,248,0.82)` + `backdrop-filter: blur(16px)`.
- `sticky top: 0` с `z-index: 50`.
