## Раздел «Админ» — только для тебя  ✅

У тебя на бэкенде уже есть поле `users.role` и переменная окружения
**`ADMIN_EMAIL`**, которая делает указанную почту админом. Это «родной» способ.

**Самый надёжный путь (рекомендую):**
1. В Railway задай `ADMIN_EMAIL=ddv1121@yandex.ru` (если ещё не задано).
2. Зайди этой почтой — бэкенд проставит тебе `role='admin'`.
3. Фронт уже гейтит по `role` (см. `lib/adminConfig.js` → `isAdmin`).

Доп. подстраховка: в `ADMIN_EMAILS` (там же) лежит список почт — если по какой-то
причине роль не проставилась, пункт «Админ» всё равно покажется этой почте.

- **App.jsx** закрывает роут `/admin`: не-админа кидает на `/dashboard`, гостя — на `/login`.
- **Layout.jsx** показывает пункт меню «Админ» только когда `isAdmin(user) === true`.

## Что комплект ждёт от твоего кода

`useAuth()` — твой хук из `lib/auth` (Спринт 1). Комплект написан мягко:
- обязательно: **`user`** (объект пользователя или `null`);
- желательно на `user`: `email`, `role`, `credits` — если их нет, ничего не падает,
  просто баланс покажет 0, а «Админ» — по списку почт;
- опционально: `logout` (функция) и `loading` (флаг) — используются, если есть.

Менять имена полей **не нужно** — всё читается безопасно. Это и есть «сигнатура»:
просто перечень того, что хук отдаёт.
